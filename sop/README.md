# SOP

SOP collects standard operating procedure skills for repeatable engineering and analysis workflows.

## Skills

- `submit-mr`: create a merge request (GitLab) or pull request (GitHub) from the current branch, auto-detecting the forge from the `origin` remote and driving `glab` or `gh` accordingly.
- `cherry-pick-public`: separate public-safe files from a mixed private branch by comparing against `public/main`, honoring `.public-exclude`, and preparing selected paths for a public commit.
- `scientific-analyst`: analyze surprising empirical results with falsifiable hypotheses, explicit evidence status, and concrete experiment designs.
